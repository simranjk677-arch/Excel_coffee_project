COFFEE SHOP SALES DASHBOARD
Developed an interactive coffee sales dashboard using Microsoft Excel to analyze sales performance and customer trends. The project includes data cleaning, transformation, and visualization using advanced Excel features such as Pivot Tables, Charts, and Conditional Formatting.

Key insights such as top-selling products, revenue trends, and customer purchasing behavior were highlighted to support better business decision-making. Automated calculations and dynamic dashboards were implemented to improve efficiency and provide real-time analysis.

Advanced Excel( formulas and power query editor)
Data Cleaning        
Pivot Tables       
Data Visualization             
Dashboard Creation                
Business Analysis
